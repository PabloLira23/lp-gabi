# Landing Page | Gabriela Alencar

Landing page institucional desenvolvida para a nutricionista **Gabriela Alencar**, com foco em apresentação de serviços, autoridade profissional e conversão para contato via WhatsApp.

## O que é este projeto

Este projeto é uma página única responsiva criada para divulgar:

- acompanhamento nutricional personalizado
- planos de consultoria e monitoramento
- apresentação profissional da nutricionista
- canais de contato como WhatsApp, Instagram e TikTok

A proposta visual foi construída para transmitir uma sensação de cuidado, método e proximidade, usando fotos reais da profissional, a identidade visual da marca e uma linguagem mais editorial.

## Como foi feito

A landing page foi desenvolvida com:

- `React`
- `TypeScript`
- `Vite`
- `Tailwind CSS`

### Organização da página

A landing foi dividida em blocos principais:

1. `Hero`
   Apresenta a proposta principal da nutricionista com CTA de agendamento e imagens de destaque.

2. `Como funciona`
   Explica as etapas do acompanhamento nutricional em uma sequência clara.

3. `Planos e serviços`
   Mostra os formatos de atendimento disponíveis.

4. `Sobre mim`
   Reforça autoridade, posicionamento profissional e áreas de atuação.

5. `Contato`
   Direciona o usuário para os canais principais com ações rápidas.

## Decisões de design

Algumas escolhas feitas durante a construção:

- uso da logo real da profissional no topo da página
- favicon personalizado com a identidade da marca
- aplicação de fotos reais para dar credibilidade e presença humana
- composição visual com paleta suave em verde, claro e tons quentes
- foco em botões de ação objetivos para facilitar conversão
- layout pensado para desktop e mobile

## Como rodar o projeto

Instale as dependências:

```bash
npm install
```

Rode em desenvolvimento:

```bash
npm run dev
```

Gerar build de produção:

```bash
npm run build
```

Visualizar build:

```bash
npm run preview
```

Rodar lint:

```bash
npm run lint
```
